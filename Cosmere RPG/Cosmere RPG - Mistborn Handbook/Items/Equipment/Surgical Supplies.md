# Surgical Supplies

**Price** 20 bx; **Weight** 3 lb.;

This satchel contains enough bandages, salves, splints, and other medical supplies to be used 10 times. When you make a *Test: `skill=med`* to treat a wounded character (or to similarly use these medical supplies), you can expend one of these uses to gain an advantage on the test.
