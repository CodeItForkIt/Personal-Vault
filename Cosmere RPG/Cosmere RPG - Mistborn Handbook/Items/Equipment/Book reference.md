# Book (reference)

**Price** 5–250 bx; **Weight** 1–5 lb.;

Each reference book contains information on a particular topic, such as a historical era, engineering, biology, or architecture. When you have time to reference a book while you make a related test using the Intellect attribute, you’re considered to have an expertise in the topic (see “[[Cosmere RPG/Cosmere RPG - Mistborn Handbook/Mistborn Handbook/04 - Ch 3 Character Statistics#Expertise Benefits|Expertise Benefits]]” in chapter 3).
