# Unkeyed Metalmind

Metalminds can usually only be used by their creator. However, some metalminds have had this limitation removed through extraordinary means.

An unkeyed metalmind, which can be made of any Feruchemical metal, has the following effects:

- It can be tapped by anyone who wields the Feruchemical power corresponding with that metal.

- It has a predetermined charge maximum, but it otherwise can be tapped like a standard metalmind.

- A charge stored in an unkeyed metalmind can be spent by anyone with that Feruchemical power, as if they had stored that charge themself. For example, an unkeyed copper metalmind allows the retrieval of memories stored by someone else.

- When an unkeyed metalmind’s charges are depleted, some patrons may be able to exchange it for a charged one, or you can do so by completing an “Exchange for a New Metalmind” goal.

- If you store a charge in an unkeyed metalmind, it is no longer unkeyed, and it becomes a backup metalmind for you.

The [[Cosmere RPG/Cosmere RPG - Mistborn Handbook/Mistborn Handbook/17 - Appendix 2 Tables|Unkeyed Metalminds by Tier]] table suggests an appropriate charge maximum for this reward.
