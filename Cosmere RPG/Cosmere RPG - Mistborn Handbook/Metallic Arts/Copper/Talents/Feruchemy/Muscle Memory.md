# Muscle Memory

**Activation:** 8

*Your greater body awareness aids you in recalling the physical components of an activity.*

When you use **Tap Memory** to recall an expertise, you also gain an advantage on related physical tests until the end of the scene. For example, if you recall a weapon expertise, you gain an advantage on attacks using that weapon.
